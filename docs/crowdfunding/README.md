# クラウドファンディング実施計画（2026年11月公開想定）

家電・ガジェット新商品の国内クラウドファンディングに関する準備資料。運営は自社（Casokdo）一括請負を前提とする。

## ファイル

| ファイル | 内容 |
|---|---|
| `cf-plan-2026.html` | 実施計画本編。①見積レビュー ②媒体比較 ③公開までの準備計画。Artifactとして公開済み |
| `見積内訳_改定案_20260730.xlsx` | 元見積（lipro_見積_0730）を改定した内訳案。A=制作運営フィー／B=広告予算枠／C=実費／D=手数料 のブロック分離、金額未記入項目の充当、追加推奨項目を反映 |
| `build_estimate_xlsx.py` | 上記xlsxの生成スクリプト（`pip install openpyxl` 後、リポジトリルートで実行） |
