# 観測指標の定義（METRICS）

## 主要指標

| 指標 | 定義 | 記号 |
|---|---|---|
| 言及ポジション | AI回答内での自社の扱い | ◎ featured（筆頭・カテゴリ代表で紹介）<br>○ listed（リスト内で言及）<br>△ cited_only（本文言及なし・引用リンクのみ）<br>× none（登場せず） |
| 言及率 | 観測クエリ×エンジンのうちブランド言及があった割合 | % |
| 自社サイト引用 | 引用元に `a-ms2.com` が含まれるか | own_site_cited |
| 関連メディア引用 | 引用元に掲載メディア（SHOOTEST等）・note・Yahoo!等が含まれるか | related_cited |
| 競合言及 | 同じ回答内に登場した競合スタジオ | competitors_mentioned |
| 通常検索順位 | オーガニック検索での自社順位（SerpAPI利用時のみ） | organic_rank |

## 定性チェック（手動観測時にnotesへ記録）

- **正確性**: AIの説明に事実誤認がないか（料金・アクセス・設備）
- **訴求内容**: どの特徴（自然光・北欧家具・立地）が拾われているか
  → 発信コンテンツで強調すべき軸の発見につながる
- **引用元の質**: 自社公式が引用されているか、外部媒体経由か
  → ベースライン(2026-07-15)では SHOOTEST 経由。公式サイト・noteが
  引用元に入ることが1次情報発信の成功指標のひとつ

## 施策効果の見方

`reports/summary.md` の「施策タイムライン」と「言及率の推移」を突き合わせる。

- AI検索への反映は通常 **2〜6週間** のタイムラグがある（クロール→インデックス→
  回答への反映）。施策直後の1週で判断しない
- 1指標の1週の変動はノイズの可能性が高い。**2週連続の変化**をシグナルとみなす
- note・PR記事が「引用元」に登場したら、その記事のテーマとクエリの対応を記録する
