# note記事の書き方（AIO観測データにもとづく）

AI検索に引用されることを目的としたnote記事の型。
推測ではなく、このリポジトリの観測データで実際に効果が確認できた要素だけを採用している。

## 観測で分かっていること

| 事実 | 根拠 |
|---|---|
| note記事はAIの情報源として採用される | 8/18〜9/22、`note.com` が2〜3クエリで継続的に引用元に出現 |
| 反映までのラグは約3週間 | 7/27公開 → 8/18に初引用 |
| **発信が止まると約6週間で引用が消える** | 8/19以降更新なし → 9/29から5週連続で引用ゼロ |
| タイトルの具体性が効く | 引用された7/27記事はタイトルに「神楽坂駅より徒歩6分」「2面からの自然光と北欧家具」とクエリ語＋差別化要素を併記 |

**結論: 単発では効かない。週一の継続が前提。**

## タイトルの型

```
【カテゴリ】<地名・アクセス>。<差別化要素>、<業態>「ARIGATO Living」
```

実例（引用実績あり）:
> 【スタジオ紹介】神楽坂駅より徒歩6分。2面からの自然光と北欧家具、多目的ハウススタジオ「ARIGATO Living」

守るべき点:
- **狙うクエリの語をそのまま入れる**（「神楽坂」「ハウススタジオ」「撮影スタジオ」など）
- **差別化要素を併記する**（自然光／北欧家具／フリッツハンセン／無垢材／カウンターキッチン）
- **ブランド名を必ず入れる**。AIは「属性→ブランド名」の結びつきで名前を拾う

## 本文の構成

AIが引用しやすいのは「問いに対する答えが完結している段落」。
物語として流すより、見出しごとに事実が閉じている形が有利。

1. **リード（3〜4行）** — 誰向けの、何の記事か。ここにもクエリ語とブランド名を入れる
2. **今回の撮影・事例** — 何を撮ったか、誰が使ったか、どう使ったか
3. **なぜこのスタジオが向いていたか** — 差別化要素と用途の結びつきを明示
4. **スタジオの基本情報** — アクセス・広さ・設備・備品（毎回載せる。AIが拾う事実の塊）
5. **問い合わせ導線** — 公式サイトへのリンク

### 4は毎回必ず入れる

AIは記事単体を読んで答えを作る。基本情報が抜けていると、
その記事が引用されても「名前は出るが説明できない」状態になる。
定型文で構わないので毎回入れる。

## やってはいけないこと

- 事実でないことを書かない（撮影実績・利用者名は確認が取れたものだけ）
- タイトルを抽象的にしない（「スタジオの魅力について」のような題は引用されない）
- ブランド名を省略しない（「当スタジオ」だけだとAIが名前を抽出できない）

## 公開後

公開すると `scripts/fetch_note.py` が自動で公開日を取得し、
週次レポートの「note発信の影響検証」に反映される。
手作業での記録は不要。

引用されるまで約3週間かかるため、公開直後の観測で変化がなくても異常ではない。
