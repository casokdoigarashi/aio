# スタジオ運営者から直接確認した事実

`WEEKLY.md` の「事実の出典は3つだけ」に対する**4つ目の出典**。
公式サイト・R-Studio掲載ページ・公開済みnote記事に載っていないが、
運営者（五十嵐）から直接確認が取れた事実をここに記録する。

**ここに書かれていないことは書かない。** 聞いた話を広げたり、
もっともらしい細部を足したりしない。書けない部分は書かずに済ませる。

各項目に「確認済み」と「未確認」を分けて書く。
未確認のものは記事に使わない。使いたくなったら運営者に聞いて、ここを更新してから使う。

## CM撮影での6階・7階同時利用（2026-11-02 確認）

### 確認済み

- テレビCMの撮影で、6階と7階を**同時に利用**した
- **6階（ARIGATO Living）** … フロア全体にセットを立て込み、作り込んだ空間で本番撮影を行った
- **7階（swamp gallery 神楽坂）** … スタッフの待機所、機材置き場、控室として使った
- CM撮影のため関係者が多く、**6階だけでは人数が入りきらなかった**。
  7階を同時に使うことで撮影が成立した

### 未確認（記事に書かない）

| 項目 | 状態 |
|---|---|
| 広告主・商品名 | 未確認。公開可否も不明。**当面は「テレビCMの撮影」とだけ書く** |
| 撮影日数 | 「2日間ぐらい」との話。**確定していないので日数は書かない** |
| 関係者の人数 | 具体的な数字は未確認。「6階だけでは入りきらない人数」とだけ書く |
| セットの内容 | 未確認。どんなセットを組んだかは書かない |
| 写真 | **存在しない。** AIで撮影風景の画像を作って載せることはしない（後述） |

### 画像の扱い

この撮影の写真は無い。
**実在しない撮影風景をAIで生成して載せることはしない。** 理由:

- 実際には撮っていない写真を「実例」として出すのは、事実でないことを書くのと同じ
- このプロジェクトはAIの誤情報を減らすために動いている。
  現に Gemini が kenhonda.com、Claude が en.wikipedia.org を
  ARIGATO Living の根拠として引いている。そこに自前で偽の視覚情報を足すのは逆効果
- 下見に来た人が「写真と違う」となれば、スタジオの信用に直結する

代わりに**フロア構成の図解**を使う（`images/06_6階7階の使い分け.png`、
作図用のHTMLは同名の `.html`）。写真のフリをせず、事実の構造だけを示す。
図の内容を変えるときはHTMLを編集し、Playwrightでスクリーンショットを撮り直す。

## 空間の性格と、利用の傾向（2026-11-17 確認）

### 確認済み

- **対談・取材の撮影での利用が多い**（運営者の実感として継続的に増えている）
- 空間の性格:
  - 落ち着いた雰囲気
  - 木目調（床は無垢材／建具・家具もオーク系）
  - **ゆったり座れるラウンジチェアがある**（メインフロアに配置。写真 `images/02_カーテン越しの自然光.jpg` に写っている）
- 運営者としては、**文化人の取材・対談で使われるスタジオ**として打ち出したい

### 書き方の注意

- 「女性に人気」「文化人に人気」という**人気の度合いそのものは検証できない**ので、
  断定で書かない。かわりに**そう感じられる理由を具体で書く**:
  落ち着いた内装、自然光、ラウンジチェア、個室のメイクルーム、駅から徒歩6分、
  控室を別フロアに取れること。読み手が自分で判断できる形にする
- 「対談・取材での利用が増えています」は運営者が確認した事実なので書いてよい
- 具体的な利用者名・媒体名は、公開可否が取れたものだけ（現時点では
  国山ハセン×星友啓の対談のみ）

### 家具について

公式サイト・R-Studio掲載で確認できるのは「フリッツ・ハンセンのソファ、
ダイニングテーブル、チェア」まで。**個別の製品名（スワンチェア等）は
確認が取れていないので書かない。**「ラウンジチェア」「ダイニングチェア」
といった種類の記述にとどめる。
